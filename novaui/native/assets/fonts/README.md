# Yuktara Sans font assets

Place the licensed Yuktara Sans OpenType files in this directory using the
exact filenames below. The native font resolver discovers these files
automatically and selects the closest configured weight/style.

Text family:
- YuktaraSans-Regular.otf
- YuktaraSans-Medium.otf
- YuktaraSans-SemiBold.otf
- YuktaraSans-Bold.otf
- YuktaraSans-Italic.otf
- YuktaraSans-BoldItalic.otf
- YuktaraSans-Light.otf

Display family:
- YuktaraSansDisplay-Regular.otf
- YuktaraSansDisplay-Medium.otf
- YuktaraSansDisplay-SemiBold.otf
- YuktaraSansDisplay-Bold.otf

For local development before the files are bundled, set
`YUKTARA_UI_FONT_DIR` to the directory containing the OTF files.

Yuktara Sans is derived from Inter. Retain the supplied Inter Open Font License
and all upstream copyright/attribution notices when redistributing the font
files. Devanagari and other scripts not covered by this font continue to use
the configured Noto Sans fallback families.
